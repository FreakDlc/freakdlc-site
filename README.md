# FreakDLC — сайт с регистрацией и входом

Регистрация и вход **только по логину и паролю** (почта не нужна). Пароли хранятся в виде хэша (scrypt), сессия — в защищённой cookie. Настройки Click GUI сохраняются в аккаунт.

## Структура проекта (папка «сайтфрика» на рабочем столе)

```
сайтфрика/
├── сайт/                 ← этот сайт (server.js + public/)
│   ├── server.js
│   ├── package.json
│   ├── README.md
│   └── public/
│       ├── index.html
│       └── downloads/    ← сюда класть zip, ЕСЛИ сервер не используется (GitHub Pages)
└── загрузка/             ← файлы, которые качает кнопка «Скачать»
    └── FreakDLC-Loader.zip
```

`server.js` отдаёт `/downloads/*` **из папки «загрузка», которая лежит рядом с папкой «сайт»**.
Если такой папки нет — берёт `public/downloads/`. Путь можно переопределить переменной `DOWNLOADS_DIR`.

## Запуск на компьютере
1. Установи Node.js 18 или новее.
2. В папке `сайт`: `node server.js`
3. Открой http://localhost:3000 — кнопка «Скачать клиент» начнёт качать zip из `../загрузка`.

Зависимости (`npm install`) не нужны.

## Ссылка на скачивание
В `public/index.html` строка: `var DOWNLOAD_URL='/downloads/FreakDLC-Loader.zip';`
- Относительный путь (`/downloads/...`) — работает с server.js и со статикой (если zip лежит в `public/downloads`).
- Абсолютный URL (`https://...`) — если zip выложен на другом хостинге/файлообменнике.

## Регистрация без сервера (GitHub Pages и т.п.)
Если `server.js` не запущен, сайт автоматически переключается на «браузерный» режим:
аккаунт хранится в localStorage того устройства, где его создали. Общих аккаунтов в этом режиме нет.

## Переменные окружения (необязательно)
`PORT`, `SECRET` (ключ сессий), `DATA_DIR` (куда писать `users.json`), `DOWNLOADS_DIR` (папка с zip).

## Подробная инструкция: как выставить на хостинг и включить скачивание
См. файл `../КАК-ЗАЛИТЬ-НА-ХОСТИНГ.md` (лежит в папке «сайтфрика» рядом с этой папкой).
